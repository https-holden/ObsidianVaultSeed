## How to write an entry

1. Open it from **[[Entries.base]]**, which has an **Unwritten** tab for what is left.
2. Set `status` to `draft`.
3. Talk into **Talk through**. Do not edit as you go. Put research under **Sources**.
4. Ask a Claude Code session to distill: it reads Talk through, writes **Distilled** and
   proposes a `short`, both as drafts. Rewrite them until they are yours.
5. Set `status` to `done`. That is the switch.
